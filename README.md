# flow

Svelte song desk. Read the songs in `entries/`, write your own, and look up a dictionary definition, thesaurus words, and rhymes while you write.

Songs you write are saved in this browser. Download gives you a markdown file you can put in `entries/` if it should ship with the site.

The public site is [longdenjay00-sketch.github.io/flow](https://longdenjay00-sketch.github.io/flow/).

```bash
npm install
npm run dev
```

Open the local URL Vite prints. `npm run build` writes the static site to `dist/`.
